本外掛程式為參考 https://github.com/tomoki1207/vscode-input-sequence 功能，建立於 Notepad++ 也能同樣運作的外掛輔助工具
以快捷鍵 Ctrl + Alt + 0 呼叫出功能清單，可以快速的在多行選取文字中，便利的建立連續編號。

This plugin is a helper tool for Notepad++, inspired by the functionality of https://github.com/tomoki1207/vscode-input-sequence, providing similar capabilities within Notepad++.
